# HPC setup

This folder contains reproducibility notes and environment definitions for running the CFRP RVE simulations on an HPC system.

The main simulations use FEniCSx, Gmsh, MPI, PETSc, and `dolfinx_mpc`.

## Important

This repository does not include credentials, SSH keys, passwords, allocation identifiers, or private filesystem paths.
